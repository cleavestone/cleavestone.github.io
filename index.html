Background

Data and AI Engineer who builds production data pipelines and the machine learning systems that run on top of them.

Currently at Solutech Limited, I own end-to-end analytics engineering — ELT pipelines that power manufacturer-facing dashboards, dbt transformations in BigQuery built on a medallion architecture (bronze → silver → gold), and monitoring of production Prefect pipelines — while leading an end-to-end computer vision project for retail shelf analytics, owning everything from annotation strategy through model training to production deployment. As part of this, I also build customer-facing dashboards in Apache Superset and Looker Studio.

On top of the warehouse I deliver demand forecasting, route optimization and computer vision systems, served as APIs so teams can use them in daily operations.

Outside my day-to-day role, my recent focus has shifted toward agentic AI system design: ReAct-style tool-calling agents, task planning, hybrid memory, and self-reflection loops, packaged as streaming production APIs. I design these systems with cost optimization, auditability, and data-privacy compliance (GDPR-aware handling) built in from the start — the same production discipline I apply to data infrastructure.
